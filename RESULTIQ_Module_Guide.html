Module 1 — config.py (Application Configuration)

Purpose: Central place for all configuration settings — no magic strings scattered across files.

SettingDetails
Secret KeyFor session signing — reads SECRET_KEY env var, falls back to a dev default
Session Lifetime30-day persistent sessions so users stay logged in
Upload & Report Foldersuploads/ and reports/ directories, auto-created at startup

Key takeaway: You pick a profile name ('development', 'testing', 'production') and the app loads the matching settings automatically.

Application Factory — app.py (Wiring Module)

Purpose: The entry point that wires everything together using Flask's application factory pattern.

What it does step by step:

  1. Creates a Flask app and loads config from config.py
  2. Creates uploads/ and reports/ directories if missing
  3. Initialises SQLAlchemy (database ORM) and Flask-Login (session auth)
  4. Registers the user_loader callback so Flask-Login can look up users by ID
  5. Adds a custom Jinja2 enumerate filter for templates
  6. Imports and registers 4 Blueprints: auth_bp, upload_bp, analyse_bp, report_bp
  7. Defines the root route / → renders index.html (landing page)
  8. Registers error handlers for 404 (Not Found) and 500 (Server Error)
  9. When run directly (python app.py), creates all DB tables and starts the dev server

Module 3 — routes/auth.py (Authentication)

Purpose: Handles user registration, login, logout, and the dashboard.

RouteMethodWhat it does
/registerGET / POST Shows registration form. On POST: validates all fields, enforces strong password rules (≥8 chars, uppercase, lowercase, digit, special char, no spaces), checks for duplicate email/username, creates the user.
/loginGET / POST Shows login form. Accepts email or username. Strips accidental trailing spaces from passwords. Sets a 30-day persistent session. Redirects to ?next= URL if present.
/logoutGET Clears session, logs out, redirects to home.
/dashboardGET Shows the user's dashboard with their 5 most recent reports.
Security: Passwords are stored as Werkzeug-hashed values (never plaintext). Login gives distinct error messages for "account not found" vs "wrong password". All routes except /register and /login require @login_required.

Module 4 — routes/upload.py (File Upload & Inspection)

Purpose: Lets users upload .xlsx / .xls mark sheets and immediately inspects their structure.

RouteMethodWhat it does
/uploadGETShows upload form + list of 5 recently uploaded files
/uploadPOSTReceives the Excel file, validates, saves, inspects, stores metadata
/upload/inspect/<file_id>GETDisplays the inspection results (sheets, columns, data types, samples)

Upload Pipeline (POST)

Upload Validation & Processing Flow
1 File Present? Check form has a file
2 Extension OK? Only .xlsx / .xls
3 Size ≤ 16 MB? Enforce upload limit
4 .xls → .xlsx Auto-convert legacy
5 Save with UUID Secure filename
6 Inspect Workbook Read sheets, columns, types
7 Save to DB UploadedFile + ActivityLog
8 Redirect → /upload/inspect

inspect_workbook() function

  • Opens the Excel file with pandas (openpyxl for .xlsx, xlrd for .xls)
  • For each worksheet: reads columns, infers data types (Integer, Decimal, Text, Date/Time, Boolean), grabs 3 sample values
  • Skips unnamed/empty columns
  • Returns a clean JSON structure stored in UploadedFile.worksheets

Module 5 — services/analyser.py (Intelligent Column Classifier)

This is the brain of ResultIQ. It automatically classifies every column as one of: marks, identity, metadata, category, empty, or text.

Zero Flask imports — pure Python + pandas, making it independently testable.

Classification Logic — classify_column()

The classifier uses a 13-step decision cascade:

StepCheckResultExample Columns Caught
1Datetime type or namemetadataDOB, Timestamp
2Identity name patterns (regex)identitySl. No, Roll No, USN, Student Name, Email, Aadhaar
3Excluded summary columns (regex)metadata / categoryTotal Marks, Percentage, CGPA, Rank, Grade, Attendance, Result
4Unnamed columnsmetadataUnnamed: 0 (from multi-row headers)
5Long names (>40 chars)metadataFree-form description columns
6Nearly empty (<5% filled)emptyPlaceholder columns
7Large numbers (median >999)identityRegistration numbers, phone numbers
8Rating / Likert guardmetadataSurvey ratings 1–5, year columns
9Subject name match + numeric datamarksMathematics, Physics, 24CS301, CIT-1, Quiz-2
10Content-driven: ≥50% numeric, ≥75% coverage, median ≤200marksUnnamed but clearly numeric score columns
11High uniqueness non-numericidentityStudent IDs with unique text
12Low cardinality textcategorySection (A/B/C), Gender
13Default fallbacktextEverything else

Header Detection — _detect_header_row()

  • Scans first 35 rows, scores each candidate based on keyword matches (Name, Roll No, Marks, subject codes) and whether the next row has data
  • Picks the highest-scoring row as the real header — handles messy sheets with title rows, blank rows, or merged cells above the actual table

Quality Metrics — _build_quality()

For every column, computes: total rows, filled count, missing count, numeric count, absent-token count, text count, unique values.

Module 6 — services/reporter.py (Report Generation Engine)

Zero Flask imports — pure Python + pandas + openpyxl. Fully testable in isolation.

What generate_report() does

Report Generation Pipeline
1 Read Marks Cols From classification JSON
2 Read Source Excel Using detected header row
3 Fix Headers Multi-row / Unnamed cols
4 Filter Rows Skip footers, signatures
5 Compute Results Total, Avg, %, Pass/Fail
6 Build Stats Summary statistics
7 Clone Workbook Preserve source layout
8 Append Analysis Formulas + styling

Computed Columns Added Per Student

ColumnFormula / Logic
Total MarksSum of all marks (absent → 0)
Subjects AppearedCount of subjects with a valid mark
AverageMean of appeared subjects' marks
Percentage(Total / max possible) × 100
ResultPASS if overall ≥40% AND every subject ≥50%; else FAIL

Excel Styling Features

  • Grey header row with bold Arial font and thick borders
  • Red highlight for marks < 50 (fail)
  • Grey highlight for absent students (AA, Abs, etc.)
  • Native Excel conditional formatting rules
  • Auto-sized column widths (names wider, marks centered)
  • Monkeypatched openpyxl writer to output cached formula values in <v> tags

Absent Token Recognition (20+ markers)

AA, Ab, Abs, Absent, NA, N/A, -, --, Nil, None, Withheld, Medical, Detained, Exempted, OD, On Duty, Leave, and more.
